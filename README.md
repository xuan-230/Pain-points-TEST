# Pain-points-TEST

我的工作工具蒐集清單

這個專案收集對我的工作有用的**免費工具**。我的工作內容是：**整理資料、做表格、寫郵件**，因此下面的工具清單都是圍繞這三個需求來篩選的。

> 原則：只收免費工具（有免費方案或免費額度就算），列出真實用途，方便自己快速找到適合的工具。

## 目錄

| 分類 | 檔案 | 重點 |
|------|------|------|
| 📋 資料整理 | [01-資料整理.md](01-資料整理.md) | 整理、篩選、彙整大量資料 |
| 📊 表格製作 | [02-表格製作.md](02-表格製作.md) | 製作表格、報表、統計圖 |
| ✉️ 郵件撰寫 | [03-郵件撰寫.md](03-郵件撰寫.md) | 撰寫、管理、自動化郵件 |
| 🗂️ 文件管理 | [04-文件管理.md](04-文件管理.md) | 雲端儲存、檔案整理與備份 |
| 🤖 AI 工具 | [05-AI工具.md](05-AI工具.md) | AI 輔助整理資料、寫表格、寫郵件 |
| 🎙️ 會議與錄音 | [06-會議與錄音.md](06-會議與錄音.md) | 手機錄音+逐字稿+摘要+輸出Word |

## 表格欄位說明

每份清單都用統一的表格格式，方便比較：

| 欄位 | 說明 |
|------|------|
| 工具名稱 | 工具名稱（點擊可前往官網） |
| 用途 | 這個工具實際能做的事 |
| 免費方案 | 免費額度或限制 |
| 平台 | Windows / Mac / 網頁版 / 手機 |
| 我的筆記 | 適合用在什麼工作情境 |

## 我的常用工作流程（範例）

1. 收集資料 → 用 **資料整理** 工具彙整
2. 製作報表 → 用 **表格製作** 工具排版輸出
3. 撰寫郵件 → 用 **郵件撰寫** + **AI 工具** 加速完成

## 如何維護這份清單

- 新增工具：依照分類放進對應的 `.md` 檔案，並用同樣的表格格式。
- 更新狀態：工具若有收費或停用，隨時修改「免費方案」欄位。
- 每次更新後，記得把檔案同步到 GitHub。
